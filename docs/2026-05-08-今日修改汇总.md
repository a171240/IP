# 2026-05-08 今日修改汇总

本说明按今天多个线程的最终工作区状态整理；有交叉或冲突的地方，以最后落地的版本为准。

## 小红书发文与封面生图

- 前端不再把旧的 `coverPrompt`、`negativePrompt`、`resolution: "2k"` 传给封面生图接口，只传正文、标题、标签和风格 ID。
- 后端统一拼接封面生图 prompt，文案模型只负责输出封面主标题、副标题和视觉风格 ID。
- 生图模型固定为 APIMart 基础 `gpt-image-2`，单次只生成 1 张图；不再走 `gpt-image-1/1.5`、`gpt-image-2-official`、`official_fallback` 或默认 2K。
- 移除 `Negative prompt:` 拼接，避免把“关注/私信/进入小程序”等负面词反向喂给生图模型。
- 标题、副标题、正文参考进入生图 prompt 前会清洗导流词，重点避免底部 CTA、私域入口、平台入口、扫码联系等会影响视频引流的元素。
- 保留人脸、局部对比、清单等画面自由度，只把导流 CTA 作为硬约束。
- 小程序发文页增加 120 秒长任务超时、错误弹窗、埋点、草稿入口条和更清晰的按钮成本展示。

## 海报生成链路

- 海报问诊提示词要求副标题必须是可直接上画面的短句，避免“适合想了解...”这类说明句进图。
- 海报 brief 增加美容行业默认副标题、卖点、权益和活动时间兜底，减少空字段导致的弱图。
- 海报模板 prompt 区分“可见文案”和“仅用于理解的上下文”，避免字段名、用途说明、目标人群说明被画到海报里。
- 小程序海报页支持“生成/出图/做图”等口语指令直接触发生图，增加生成进度面板、120 秒长请求、默认字段补齐、埋点和结果操作按钮优化。

## 登录与账号

- 小程序登录改为 `wx.login` + 昵称/头像采集，不再依赖旧的 `wx.getUserProfile` 流程。
- 登录页增加头像选择、昵称输入及对应样式。
- `auth.js` 改为 `loginWithCode(code, profile)`，统一保存 session 和 profile。

## 语音教练

- 训练历史只默认展示前 2 条，增加“展开更多/收起记录”交互。
- 语音教练首页视觉调整为更浅的米色/绿色体系，历史卡片可读性提升。
- 项目卡相关测试文案从“场景卡”收敛为“项目卡/项目训练包”。
- WebSocket 回复超时从 8 秒调整到 20 秒，降低实时回复被过早切断的概率。

## 小程序通用体验

- 全局请求与下载超时从 60 秒提高到 120 秒，适配海报和封面生图长任务。
- 内容工作台按钮拆分主文案和成本文案，避免按钮文本拥挤。
- 我的页增加页面访问、权益快照、登录、升级、订单、门店资料等埋点。
- 小红书、海报、保存图片等关键动作增加成功/失败埋点，方便排查扣点、超时和生成失败。

## 验证

- `node --test tests/xhs-cover-style.static.test.js`
- `node --test tests/voice-coach-setup.static.test.js`
- `node_modules\.bin\tsc.cmd --noEmit --pretty false`

- 已做 CTA/旧模型/旧参数关键词扫描；业务代码里不再出现 `Negative prompt`、`official_fallback`、`gpt-image-2-official`、默认 2K、多图生成等旧路径。

## 注意

- 本轮没有再继续真实调用生图 API，避免增加测试费用。
- 基础模型仍可能偶发自行生成 CTA；当前代码侧已清理可控诱因。如果后续要做到强保证，需要增加 OCR 审核或失败重试，会增加成本。
