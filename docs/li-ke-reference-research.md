# 李可个人页参考池与提炼

## Page Type

个人专家 / 实体店 AI 获客顾问型 landing page。

核心任务不是展示一个“漂亮作品集”，而是在 3 秒内回答：

- 我是谁：苏州美业一线经营者，正在做实体店 AI 获客落地。
- 我解决什么：内容生产、客户洞察、平台获客、到店转化。
- 为什么可信：10+ 年一线经验、门店实践、真实评论和文章证明。
- 下一步做什么：带真实门店问题来聊。

## Extracted Style Signals

### Layout

- 首屏要像“人物定位页”，不是产品功能页。
- 采用大字号姓名 + 一句判断，右侧放“可信证据卡”，让人先记住人，再理解业务。
- 中段使用问题清单、方法论、服务模块三段式，降低解释成本。
- 文章证明要像证据，不像普通博客列表。

### Typography

- 中文页面不能靠低对比灰字营造高级感，标题必须高对比。
- 大标题要短、硬、可复述；正文保持 1.75-2 行距。
- 英文 label 只做节奏标记，不承担关键信息。

### Color

- 主色控制在黑、暖底、深绿、铜橙四个角色内。
- 暖底负责亲近感，黑色负责权威感，深绿负责“专业/诊断”，铜橙负责提示和证据。
- 禁止白字浅底、低对比灰字、过多渐变。

### Components

- 卡片要有层级：证据卡、问题表、服务卡、文章卡不能长得一样。
- 尽量减少圆角胶囊堆叠，按钮和标签只保留必要形态。
- 数据不是装饰，要和可信度直接相关。

### Content

- 第一屏必须回答“你是谁”和“你能帮我解决什么”。
- 个人经历要连接到业务结果，不只是自我介绍。
- 方法论要命名、分步、可记忆。
- CTA 要让人带“具体门店问题”来，而不是泛泛预约。

## Design Direction

- Style keywords: editorial, field-tested, premium practical.
- Layout model: asymmetric expert landing page with evidence sidecar.
- Accent strategy: one dark authority block per major page turn; copper labels for structure.
- Density: medium-high, but use section contrast to breathe.
- Anti-patterns avoided: generic SaaS card wall, weak gray text, decorative gradients, equal-weight cards, unrelated product navigation.
