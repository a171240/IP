# 小程序主链路 UI 方向稿 V2

## 目标

这份文档用于约束下一轮 HTML 原型，不直接修改业务逻辑，也不先回填小程序。

本轮目标不是继续“换一种配色”，而是把主链路界面建立在一套更成熟的设计语言上：

- 更像高端护肤品牌的数字产品，而不是通用 SaaS 模板
- 更像经过专业编辑和工业设计推敲的界面，而不是“漂亮卡片”的堆叠
- 更克制、更安静，但仍然有材质感和品牌辨识度

## Page Type

- `xiaohongshu.html`
  页面类型：创作工作台 / 表单驱动任务页
- `drafts.html`
  页面类型：内容资产列表 / 记录页
- `voice-coach.html`
  页面类型：训练入口页 / app screen
- `mine.html`
  页面类型：账户中心 / 会员权益页

## Reference Signals

### 1. Jony Ive / LoveFrom

来源：

- [LoveFrom](https://www.lovefrom.com/)
- [Jony](https://www.lovefrom.com/jony)
- [Apple New Design Gallery](https://developer.apple.com/design/new-design-gallery/)

提炼信号：

- 材质必须分层：控制层和内容层不能是同一种表面
- 高级感主要来自比例、边界、折射感和安静的留白
- 真正重要的元素看起来更“轻”，不是更重
- 玻璃只能是功能层语言，不应吞掉正文阅读层

### 2. Dieter Rams

来源：

- [Ten Principles for Good Design](https://tenprinciples.design/)

提炼信号：

- 工具页要诚实，不要把业务控件包装成营销画面
- 每个元素必须有理由存在
- 减少“同级卡片”数量，让主任务更明确
- 高级感和克制是同一个问题，不是两个问题

### 3. Susan Kare

来源：

- [Macintosh Archives Interview](https://web.stanford.edu/dept/SUL/sites/mac/primary/interviews/kare/index.html)
- [Kare Prints About](https://kareprints.com/pages/about)

提炼信号：

- 状态、入口、图形提示要一眼看懂
- 标签不应承担段落说明的职责
- 可识别性比装饰性更重要

### 4. Mike Matas

来源：

- [Mike Matas](https://mikematas.com/)
- [Push Pop Press About](https://pushpoppress.com/about/)

提炼信号：

- 软件的高级感很大一部分来自手感
- 控件反馈应该短、轻、准确
- 页面中的“魔力”来自材质和交互一致，不来自炫技动画

### 5. Khoi Vinh

来源：

- [Subtraction](https://www.subtraction.com/2010/)

提炼信号：

- 页面秩序来自排版系统，不来自单个组件设计
- 标题、说明、数据、动作的节奏必须能在 3 秒内被扫读
- 网格、对齐和留白比阴影更能决定“高级”

### 6. Pedro Duarte / Rauno Freiberg / Emil Kowalski / Joey Banks

来源：

- [Pedro Duarte](https://ped.ro/)
- [Rauno Freiberg](https://rauno.me/)
- [Emil Kowalski](https://emilkowal.ski/)
- [Joey Banks](https://www.joeyabanks.me/)

提炼信号：

- 设计和前端实现是一体化问题
- 细节精致感来自状态统一，而不是只做静态稿
- 现代高级感不等于“发光 + 渐变 + 玻璃 everywhere”
- 组件应该有清晰语义和稳定比例

## Design Direction

### 三个关键词

- 雕塑感
- 编辑感
- 温冷平衡

### 一个布局模型

深色品牌顶区 + 浮层控制带 + 浅色实体内容面。

解释：

- 顶区负责品牌气质、页面标题和少量引导
- 控制层负责返回、标签、tab、轻操作，允许使用玻璃质感
- 内容层负责表单、列表、账户信息、结果信息，必须稳定、可读、可承载

### 一个主强调策略

不再靠黑金。主强调改为“低饱和玫瑰棕 / 软铜粉”体系，搭配鼠尾草绿辅助状态。

- 主强调：品牌与主 CTA
- 辅助绿：成功 / 已配置 / 已登录
- 中性深灰：结构和信息
- 奶油白 / 陶瓷白：主内容承载面

### 一个密度等级

中高密度。

理由：

- 这是工具型小程序，不适合大量空 hero 和营销式铺陈
- 但作为美容行业产品，仍然需要比纯后台稍微更舒展

### 三个必须避免的反模式

- 把所有区块做成同一种卡片
- 把玻璃质感铺到正文和表单层
- 只靠阴影和配色解决层级问题

## Design Rules

### 1. 材质系统

- `品牌顶区`
  使用更深的莓黑 / 酒棕底，承担品牌气质
- `控制层`
  使用半透明玻璃材质，只给：
  - 顶部圆按钮
  - badge / chip
  - tabbar
  - 小型次级操作按钮
- `内容层`
  使用实体陶瓷白 / 暖石白，边界更清晰，更像真实承载面

### 2. 字体系统

- `Display Serif`
  只用于首屏大标题和少量 section title 强调
- `UI Sans`
  用于正文、表单、标签、按钮、列表信息
- 规则：
  - 不让 serif 参与密集信息区
  - 不再用大面积全粗体堆“气势”
  - 中文标题更重视字距和行高，而不是只加粗

### 3. 排版系统

- section 之间必须有明显呼吸差，不是每块 24px 平铺
- 同一页内只能有一个绝对主视觉
- 标题、说明、操作之间必须建立阅读顺序：
  - 主标题
  - 作用说明
  - 当前状态
  - 关键动作
- 列表页优先保证扫描效率，不优先做视觉装饰

### 4. 组件规则

- `按钮`
  - 主按钮：实体材质，稳定、厚实、边界干净
  - 次按钮：轻玻璃或轻描边
  - ghost：仅用于弱操作
- `chip / tag`
  只表达分类、状态、筛选，不承载大段说明
- `卡片`
  必须拉开角色：
  - hero 卡
  - 信息卡
  - 表单块
  - 列表项
  - 工具入口卡
- `输入框`
  更像“精致容器”，不是黑洞或纯边框框

### 5. 阴影系统

- 外层壳：宽而浅，负责整体悬浮
- 控制层：短阴影 + 顶部高光线
- 内容层：更短更稳，靠近表面

说明：

- 不允许再出现“所有卡片一个大模糊阴影”的处理

### 6. 动效系统

- 默认交互时长：
  - 快反馈：`160ms - 180ms`
  - 层级变化：`220ms - 260ms`
- 动作规则：
  - hover：轻提亮 / 轻上浮
  - active：轻压，不弹跳
  - focus：细 ring，不做粗色框
- 原则：
  - 动效只服务层级确认
  - 不把动效当成“高级感滤镜”

## Page-Level Mapping

### 发文页 `xiaohongshu.html`

目标：

- 更像“高端服务品牌的创作控制台”
- 不像说明页，也不像黑色表单模板

规则：

- 顶区保留品牌氛围，但压缩说明性文案
- 主任务区必须尽快进入输入与选择
- 内容类型、主题、关键词、强度、门店档案形成单线程表单流
- “结果”和“发布”必须是独立层，不再混成一块

### 草稿页 `drafts.html`

目标：

- 更像内容资产库
- 扫一眼能知道有没有内容、最近状态如何、下一步能做什么

规则：

- 标题、时间、状态优先
- 封面只是预览，不得压过文字信息
- 空状态要像“精致的引导”，不是普通 empty panel

### 话术练习页 `voice-coach.html`

目标：

- 更像专业训练入口，而不是普通功能列表

规则：

- 只有一个绝对主动作：开始训练
- 顾客档案和场景卡是资产入口，不抢主动作
- 气质比发文页更冷静、更专业

### 我的页 `mine.html`

目标：

- 更像高端会员中心 / 服务控制台
- 不像设置页堆叠

规则：

- 顶区做账户身份和状态
- 套餐 / 积分区做权益焦点
- 订单和工具分层降级
- “升级 / 购买”是唯一主 CTA

## Implementation Plan

### Phase 1：先改全局壳层和字体

- 重写颜色 token
- 重建字体系统
- 先把品牌顶区、内容面、控制层三层关系做出来

### Phase 2：先改 `mine.html`

原因：

- 它最能暴露“高级感到底来自哪里”
- 如果会员中心都立不住，其他页面也会继续漂

### Phase 3：改 `xiaohongshu.html`

- 把表单结构、结果层级、CTA 主次拉开

### Phase 4：改 `drafts.html` 和 `voice-coach.html`

- 一个拉列表秩序
- 一个拉入口结构和训练气质

## Validation Notes

### 审核标准

- 是否摆脱“模板卡片感”
- 是否仍然适合美容行业，而不是奢侈品电商
- 是否一眼能看出每页的主任务
- 字体是否终于像一个完整系统，而不是临时搭配
- 玻璃材质是否只出现在该出现的地方
- 阴影是否更像材质，而不是效果

### 当前执行边界

- 当前只做 HTML 审查稿
- 不回填小程序
- 不改业务逻辑
- 通过这份方向稿约束下一轮 HTML 迭代
