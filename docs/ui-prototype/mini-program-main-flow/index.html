主链路审查

美容小程序主链路总览

这版只保留风格判断、页面角色和下一轮重点，不再把总览页做成说明文档。

本轮判断

先统一四个主页面，再决定什么时候回填小程序。

  • 同一套首屏骨架
  • 同一套按钮与状态语言
  • 不同页面只换主色，不换逻辑
方向：高端护肤服务感 方法：先 HTML 审查，再回填小程序 原则：控件轻，正文稳
四页角色

先看角色是否成立

先看页面职责是否清楚，再看颜色和细节是否够贵。

Page 01 发文工作台

发文工作台

把方向、正文生成和补充资产拆成清楚主次，不让所有动作同时争夺注意力。

  • 主任务是输入与生成
  • 正文先成立，封面后补
Page 02 内容资料库

内容资料库

标题、时间、状态和下一步动作优先，封面只做缩略预览，不再抢正文层级。

  • 扫描效率先于装饰
  • 草稿是资产，不是介绍页
Page 03 训练入口

训练入口

首页只保留开始训练和两个资源入口，把注意力还给训练本身，而不是说明文字。

  • 一个主动作，两个次入口
  • 反馈更轻，节奏更稳
Page 04 会员中心

会员中心

账户身份、套餐权益、订单与工具分层清楚，让升级 / 购买成为唯一主 CTA。

  • 头部更像身份封面
  • 会员价值放在最前面
下一步

先收口总览与会员页，再准备回填小程序。

如果主页面方向已经成立，下一步就不再继续换色，而是把这套规则稳定地落回 WXML/WXSS。

  • 继续收圆角、chip、按钮和服务行的比例
  • 把总览页变成真正的设计控制面
  • 确认之后再开始回填小程序页面
