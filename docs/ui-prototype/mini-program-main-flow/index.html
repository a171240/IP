UI 审查稿 · Phase 1

小程序主链路静态审查稿

这一版先不碰真实逻辑，只验证四个主 Tab 页的层级、密度、文案口吻和主动作是否更像能上线的正式产品。

  • 统一收掉英文 eyebrow，中文标签只保留帮助决策的内容。
  • 发文页改成单一任务工作台；草稿页改成列表库；话术练习页继续做视觉锚点；我的页改成账户中心。
  • 所有状态、标题、封面、链接均为静态假数据，方便先审方向，再回填到 WXML / WXSS。
发文工作台 首屏只服务“输入条件 → 生成内容”，结果、素材、发布拆成更清楚的顺序。 草稿库 弱化说明，强化标题、状态、时间和继续编辑，页面更像内容资产库。 话术练习 保留专业锚点，只保留一个主动作和两个功能入口。 海报助手 门店只说需求、上传参考图，系统追问补齐信息后生成可发布海报。 我的 收紧账号区和订阅区，把升级/购买做成唯一强 CTA。
