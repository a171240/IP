# 美容院沟通方法库

> 这份文件不放顾客原话，专门沉淀“美容师怎么接”。  
> 依据 [美容师精进手册.pdf](D:/桌面/美容师精进手册.pdf) `194-201` 页的沟通方法，以及 `181-193` 页里真正对训练有帮助的售前八大关思路整理。  
> 目标不是复刻手册原回答，而是把可用的方法抽成现代、尊重式、专业式的训练规则。

## 总原则

- 先接住顾客情绪，再谈事实，再推进下一步。
- 允许顾客犹豫，不用压迫式成交，不替顾客做决定。
- 不用“错过今天就没机会”“你不做会更严重”“我帮你做决定”这类话。
- 价格、怀疑、犹豫类问题优先用 `Feel / Felt / Found` 思路，而不是直接反驳。
- 回答只推进一个清晰下一步：继续澄清、给案例、说明边界、安排体验、记录档案。

## 1. 结构化倾听

- 来源：手册 `194-196` 页
- 适用时机：顾客一上来带情绪、带判断、带抱怨时。
- 核心动作：
  - 先判断她说的是 `情绪`、`事实`、还是 `期待`。
  - 一旦出现“总是、老是、每次、经常、永远”这类词，先识别为情绪表达，不急着辩对错。
  - 用 `who / when / where / what` 把事实问清楚。
  - 最后再确认她真正想要的是什么，例如安全感、效果、节省时间、先低风险体验。
- 禁忌说法：
  - “你别担心。”
  - “其实没有那么严重。”
  - “你想多了。”
- 现代化示例：
  - 顾客：“我就怕做完又红又肿，影响明天见人。”
  - 美容师：“我听出来你现在最在意的是恢复期别影响安排。先让我确认一下，你是担心泛红持续到明天，还是担心会有更明显的不适？”

## 2. 反向叙述

- 来源：手册 `197-198` 页
- 适用时机：顾客信息零散、意图不清、说了一半停住时。
- 核心动作：
  - 第一步先点破并接纳情绪。
  - 第二步用自己的话复述你理解到的事实。
  - 第三步把顾客期待翻译成可执行动作，让顾客确认。
- 禁忌说法：
  - “你别生气，你别着急。”
  - “我懂了我懂了，你先听我说。”
  - 没确认事实就直接推荐项目。
- 现代化示例：
  - 顾客：“我不是说完全不做，就是怕办了卡以后服务变样。”
  - 美容师：“明白，你不是排斥护理本身，你是在意前后服务别有落差。我的理解对吗？如果是，那我先把后续服务流程、预约机制和谁来跟进给你讲清楚。”

## 3. Feel / Felt / Found

- 来源：手册 `199-201` 页
- 适用时机：价格贵、怕麻烦、怕踩坑、担心不值得时。
- 核心动作：
  - `Feel`：先承认顾客现在的感觉是真的。
  - `Felt`：用“很多顾客一开始也会这样想”建立同侧感。
  - `Found`：最后再给出你想让她看到的新发现，例如边界、区别、价值点。
- 禁忌说法：
  - “这不贵。”
  - “你这个担心没必要。”
  - “别人都能接受，你为什么不行？”
- 现代化示例：
  - 顾客：“你们这个项目价格不低。”
  - 美容师：“嗯，这个顾虑很正常，第一次听价格时不少顾客也会先停一下。后面她们决定继续，通常不是因为我们讲得多，而是她们把流程、适合边界和能不能先低门槛体验看清楚了。你要是愿意，我先把这三点说透。”

## 4. 服务关

- 来源：手册 `185` 页
- 适用时机：任何首次接待和办卡前后。
- 核心动作：
  - 服务先于销售。
  - 不买和买都保持基本一致的尊重与耐心。
  - 办卡前后的态度、流程、卫生和说明口径要一致。
- 禁忌说法：
  - 体验时过度热情，顾客犹豫后立刻冷下来。
  - 把“服务一致性”问题回答成空口承诺。
- 现代化示例：
  - “你现在先不用决定要不要办卡，我先把流程和适合边界讲清楚，你再判断这件事值不值得继续。”

## 5. 熟人关

- 来源：手册 `186-187` 页
- 适用时机：破冰、建立关系、进入需求深挖前。
- 核心动作：
  - `80% 听，20% 说`。
  - 用轻量问题了解工作状态、作息、皮肤困扰、时间安排、预算边界。
  - 以自然聊天方式做基础建档，不要盘问式发问。
- 禁忌说法：
  - 连珠炮式套信息。
  - 刚见面就问隐私、婚姻、消费能力。
- 现代化示例：
  - “你平时是久坐、熬夜多，还是经常在外跑？我想先判断你这个状态更像是缺水、屏障压力，还是作息带来的问题。”

## 6. 大夫关

- 来源：手册 `188-190` 页
- 适用时机：顾客愿意继续沟通，开始听你做专业判断时。
- 核心动作：
  - 先说顾客现有优势，再指出 2-3 个真实问题。
  - 不把问题渲染成恐吓，而是讲清“现在最值得先处理哪一个”。
  - 问顾客最想改善到什么程度，再给方案。
- 禁忌说法：
  - 一上来就只说问题。
  - 用夸张后果制造焦虑。
  - 直接替顾客选高价方案。
- 现代化示例：
  - “你底子其实不差，主要是这两个点拉低了整体状态：一个是敏感泛红，一个是肤色发闷。你更想先解决哪一个？我们可以只围绕那个点先做低风险方案。”

## 7. 销售关

- 来源：手册 `191-193` 页
- 适用时机：顾客已经问到价格、方案、要不要继续。
- 核心动作：
  - 先听完异议。
  - 尊重并复述顾虑。
  - 澄清她到底卡在哪一个点。
  - 给边界清晰、证据明确、下一步明确的回答。
  - 可以用二选一，但只能用于“下一步动作”的选择，不能用于强逼成交。
- 禁忌说法：
  - “今天就是最后一天。”
  - “你现在不做以后会更严重。”
  - “我帮你做决定吧。”
- 现代化示例：
  - “你现在主要是在意价格，还是更在意先确认安全和效果？我们先只解决一个点，不着急同时做决定。”

## 8. 档案关

- 来源：手册 `183` 页
- 适用时机：接待后、沟通中、体验后。
- 核心动作：
  - 记录稳定信息：姓名、年龄、职业、联系方式、生日、爱好、肤质、消费带宽。
  - 记录动态信息：这次最在意的问题、过敏/失败经历、能接受的频率、是否需要先试做。
  - 后续顾客档案设计优先从这些字段长出来，而不是一上来堆很多标签。
- 禁忌说法：
  - 为了填表而填表。
  - 不解释为什么问这些问题。
- 现代化示例：
  - “我简单记一下你的作息和皮肤反应点，后面不管你今天做不做决定，我们下次聊也不用从头重复。”

## 训练落地规则

- 顾客一旦提到 `价格 / 不信任 / 没时间 / 效果承诺 / 安全恢复 / 服务会不会变`，先用 `结构化倾听 + 反向叙述`。
- 顾客明显在说“太贵 / 不值 / 怕踩坑 / 先想想”，优先用 `3F`。
- 任何时候都不把顾客推进到“被你说服”，而是推进到“她觉得你听懂了她，并且下一步是合理的”。
